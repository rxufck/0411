# Бот «ПДД»: приветствие, подписка, напоминания

Всё работает в одном Cloudflare Worker (`worker.js`). Токен бота хранится только в его секретах.

## Что настроено в @BotFather (без сервера)

Описание, краткое описание, команды, гифка-приветствие и кнопка меню «Решать тесты» с адресом приложения.

## Worker

| Что | Значение |
|---|---|
| Имя | `pdd-bot` (`https://pdd-bot.r4ufism.workers.dev`) |
| Секрет `BOT_TOKEN` | токен от @BotFather |
| Секрет `WEBHOOK_SECRET` | случайная строка из букв и цифр |
| Binding `KV` | namespace `pdd-users` (пользователи, подписки, напоминания) |
| Cron | `0 16 * * *` (19:00 по Москве) |

Подключить бота после смены кода: открыть `https://<worker>/setup?key=<WEBHOOK_SECRET>`.

## Что делает

- `/start`: приветствие и кнопка «Открыть тренажёр», включает напоминания. `/stop` их выключает.
- `/api/status` (из приложения): запоминает дату экзамена и последнее занятие, отдаёт срок подписки. Подпись `initData` проверяется.
- `/api/invoice` (из приложения): создаёт ссылку на подписку, 150 Stars на 30 дней.
- Платёж: бот подтверждает `pre_checkout_query`, по `successful_payment` записывает срок подписки.
- Cron: раз в день пишет тем, кто сегодня не занимался. Если Telegram ответил 403, человека больше не беспокоим.

## Подписка

Бесплатно: обучение, карточки, жизни. По подписке: экзамен и разбор ошибок. Вне Telegram (обычный браузер) всё открыто.

## Деплой кода

Файл `worker.js` читаемый. В Cloudflare загружена минифицированная копия (`npx rolldown bot/worker.js --minify --format esm`), потому что редактор там принимает код только набором с клавиатуры.
