# Приветствие бота

## Что видит человек, который впервые открыл бота

Пока он ничего не нажал, Telegram показывает **описание бота** и **картинку-гифку** над ним.
Это настраивается в @BotFather и не требует сервера.

| Команда в @BotFather | Что вставить |
|---|---|
| `/setdescription` | Тренажёр билетов ГИБДД. Теория блоками, настоящие вопросы с подсказками, экзамен на 20 вопросов и карточки на свайп. Нажми «Начать» и порешай первый блок за пять минут. |
| `/setabouttext` | Билеты ГИБДД с теорией и подсказками: учи ПДД и готовься к экзамену |
| `/setdescriptionpic` | Файл `bot-welcome-640x360.gif` (лежит в папке «ПДД», размер 640×360) |
| `/setcommands` | `start - Открыть тренажёр` |

## Сообщение «Привет, заходи, порешай тесты» после нажатия «Начать»

Бот сам напишет приветствие и кнопку «Открыть тренажёр». Для этого нужен небольшой сервер: код в `worker.js`.
Самый простой вариант — бесплатный Cloudflare Workers:

1. Зарегистрируйтесь на cloudflare.com → Workers & Pages → Create → Worker. Вставьте код из `worker.js`.
2. В Settings → Variables and Secrets добавьте:
   `BOT_TOKEN` (секрет, токен бота), `WEBHOOK_SECRET` (секрет, любая случайная строка из букв и цифр),
   `APP_URL` (адрес приложения).
3. Подключите бота к Worker, открыв в браузере (подставьте свои значения):
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС_WORKER>&secret_token=<WEBHOOK_SECRET>`

Токен бота никому не передавайте, ни мне, ни в чат: он вводится только вами в Cloudflare и в адресе из шага 3.
