# 🚦 ПДД квест — изучение ПДД для школьников

Яркое приложение для подготовки к теории ПДД для учеников автошкол. Сделано по мотивам Duolingo. Ученик не просто выбирает варианты, а **учится**: читает короткое объяснение, сразу проверяет себя, тренируется с подсказками и только потом сдаёт контрольную. Маскот — весёлый инспектор.

## Система обучения

Курс разбит по главам ПДД РФ на **7 этапов и 16 тем**:

| Этап | Темы (главы ПДД) |
|---|---|
| 1. Основы | Основы и обязанности (гл. 1, 2, 4, 5) |
| 2. Дорожные знаки | Предупреждающие · Приоритета · Запрещающие · Предписывающие и особые (Прил. 1) |
| 3. Разметка и сигналы | Разметка (Прил. 2) · Светофор и регулировщик (гл. 3, 6) |
| 4. Движение по дороге | Манёвры (гл. 8, 9) · Скорость и обгон (гл. 10, 11) · Остановка и стоянка (гл. 12) |
| 5. Перекрёстки и пешеходы | Перекрёстки (гл. 13) · Пешеходы и переезды (гл. 14, 15) |
| 6. Особые условия | Магистрали и жилые зоны (гл. 16, 17) · Свет и сигналы (гл. 7, 19) · Буксировка и перевозки (гл. 20–23) |
| 7. Безопасность | ДТП, первая помощь, исправность машины |

Каждая тема проходится в **4 шага**:

1. **📖 Теория.** 3–6 карточек: объяснение простыми словами, картинка (знак, светофор, перекрёсток), блок «Запомни» с подсказкой-запоминалкой и пункт ПДД. После каждой карточки вопрос «Проверь себя»: пока не ответишь верно, дальше не пройти. При ошибке просят перечитать карточку.
2. **💡 Практика с подсказками.** Перед ответом можно взять подсказку (за неё меньше XP). Первая ошибка не провал: вариант зачёркивается, показывается наводящая подсказка и кнопка «Теория», можно попробовать ещё раз. Задания с ошибкой возвращаются в конце урока.
3. **🔁 Закрепление.** Новые вопросы, «Найди знак», «Соедини пары».
4. **🏁 Контрольная.** 10 вопросов без подсказок, нужно 8 верных. Только после неё тема считается освоенной ⭐.

Следующая тема открывается после теории и практики предыдущей.

**Повторение.** Каждая ошибка попадает в раздел «Повторение» с группировкой по темам. Вопросы повторяются по интервалам (система Лейтнера: 1 → 3 → 7 → 16 дней). Каждая исправленная ошибка возвращает ❤️. Во вкладке «Все темы» видна точность по каждой теме, там же можно перечитать теорию.

**Мотивация.** Опыт и уровни («Новичок» → «Легенда ПДД»), серия дней, 5 сердечек (восстанавливаются по одному каждые 20 минут), ежедневные задания с наградами, награда за серию в 7 дней и 9 достижений. В профиле есть статистика: процент верных ответов, самая сложная и любимая тема, слабые темы.

## Другие режимы

- **🚗 Город.** Поездка с инструктором: он даёт команду, ученик выбирает траекторию на перекрёстке или действие, машины проезжают в правильном порядке, затем пояснение. Иногда инструктор хитрит и даёт команду, которую по правилам выполнять нельзя.
- **📝 Экзамен по официальным билетам ГИБДД** (категории A, B, M: 40 билетов, 800 вопросов с картинками):
  - экзамен по случайному билету по правилам ГИБДД: 20 вопросов, 20 минут, не больше 2 ошибок и не две в одном блоке; за каждую ошибку +5 вопросов из того же блока и +5 минут;
  - «Билеты 1–40» с цветной сеткой результатов;
  - «Вопросы по темам» (26 тем, как в билетах);
  - «Марафон» по 50 вопросов: сначала те, что ещё не встречались;
  - закладки ☆ и ошибки (они попадают в «Повторение»).
  В каждой теме курса есть кнопка «Вопросы из билетов ГИБДД», а в контрольную входят 3 настоящих экзаменационных вопроса.
- **🚸 Справочник знаков** со всеми знаками и описаниями.

Прогресс хранится в `localStorage` браузера, сервер не нужен.

## Запуск

```bash
npm install
npm run dev       # разработка: http://localhost:5173
npm run build     # сборка в dist/ — статические файлы, можно выложить на любой хостинг
npm run preview   # посмотреть собранную версию
```

### Графика

Машинки, деревья и дорожные ограждения в сценах — [Kenney Racing Pack](https://kenney.nl/assets/racing-pack) (CC0, лежат в `public/kenney/`). Маскот-инспектор — 3D-рендер с вырезанным фоном (`public/mascot/`: фигура и голова для аватара). Дорожные знаки, светофоры, схемы перекрёстков и траектории нарисованы кодом.

### Обновление билетов

Билеты лежат в `public/tickets/` (`ab.json` и картинки WebP). Их готовит скрипт из открытого набора данных [etspring/pdd_russia](https://github.com/etspring/pdd_russia), который обновляется раз в квартал:

```bash
git clone --depth 1 https://github.com/etspring/pdd_russia /tmp/pdd_russia
python3 -I scripts/import-tickets.py /tmp/pdd_russia   # нужен Pillow
```

Служебная страница `#gallery` (например, `http://localhost:5173/#gallery`) показывает все знаки и дорожные ситуации разом. Она нужна, чтобы проверять контент.

## Как устроено

- **React + TypeScript + Vite**, без UI-библиотек.
- Вся графика нарисована в SVG кодом:
  - `src/components/Sign.tsx` — дорожные знаки РФ;
  - `src/components/Scene.tsx` + `geometry.ts` — движок перекрёстков: дороги с любым числом полос, разметка, светофоры, знаки, машины, пешеходы, траектории и анимация проезда по очереди;
  - `src/components/Pictures.tsx` — светофор, регулировщик, инструктор;
  - `src/components/Art.tsx` — маскот-инспектор (картинка + эмоция-значок и анимация по настроению), городской фон, миниатюры тем.
- Контент лежит отдельно и легко дополняется:
  - `src/data/theory.ts` — карточки теории по темам (с вопросами «Проверь себя»);
  - `src/data/questions2.ts` — вопросы с подсказками и подсказки к основному банку;
  - `src/data/goals.ts` — ежедневные задания и достижения;
  - `src/data/questions.ts` — вопросы (правильный ответ пишется первым, при показе варианты перемешиваются);
  - `src/data/city.ts` — задания режима «Город»;
  - `src/data/signs.ts` — справочник знаков (из него же автоматически получаются вопросы «Как называется знак?», «Найди знак» и «Соедини пары»);
  - `src/data/course.ts` — этапы, темы, шаги обучения, сборка уроков и экзаменационных билетов.

### Как добавить вопрос с перекрёстком

```ts
q('crossroads', 'Кто проедет первым?', ['Автомобиль А', 'Вы'], 'Пояснение…', 'п. 13.11', {
  kind: 'scene',
  scene: cross({}, [me(), car('А', 3)]), // 3 — машина справа (восток)
});
```

Направления дорог: `0` — юг (снизу, откуда едет игрок), `1` — запад, `2` — север, `3` — восток. Полосы нумеруются от осевой линии: `0` — левая.

> Вопросы составлены по ПДД РФ для подготовки к экзамену. Официальные экзаменационные билеты могут отличаться формулировками. Перед экзаменом сверяйтесь с актуальной редакцией Правил.
