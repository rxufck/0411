# ПДД квест как мини-приложение Telegram

Приложение уже умеет работать внутри Telegram: оно само определяет, что запущено там, и
подстраивается. Вне Telegram всё работает как раньше.

## Что уже сделано в коде

- Подключён официальный скрипт `telegram-web-app.js` (`index.html`), логика в `src/telegram.ts`.
- Приложение раскрывается на весь экран, цвета шапки и фона совпадают с дизайном.
- Свайп вниз не закрывает приложение: он мешал бы прокрутке и карточкам со свайпом.
- Прогресс хранится не только на устройстве, но и в облаке Telegram-аккаунта
  (`CloudStorage`): ученик открывает приложение с другого телефона и видит то же самое.
  Побеждает более свежая копия. Свой сервер для этого не нужен.
- Имя из профиля Telegram подставляется на экране знакомства.
- Вибрация на верные и неверные ответы.
- Кнопка «Назад» Telegram закрывает верхний слой: окно темы, урок, страницу.

## Что нужно сделать вам (нужны ваши аккаунты, я это сделать не могу)

1. **Разместить сборку по адресу https.** Telegram открывает только https.
   Подойдут GitHub Pages, Netlify или Vercel. Сборка:
   ```bash
   npm install
   npm run build
   ```
   Папка `dist` и есть сайт (около 12 МБ, из них 11 МБ фото билетов).
2. **Создать бота.** В Telegram откройте @BotFather → `/newbot` → имя и username.
3. **Подключить приложение.** @BotFather → `/newapp` (или `/mybots` → бот → Bot Settings →
   Menu Button → Configure) → укажите адрес из шага 1.
4. Откройте бота и нажмите кнопку меню: приложение запустится внутри Telegram.

Токен бота никому не отправляйте и не вставляйте в код приложения: он нужен только серверу.

## Что потребует сервера (следующий этап)

- **Оплата подписки.** Для цифровых товаров в мини-приложениях Telegram требует Telegram Stars.
  Нужен небольшой сервер: он создаёт ссылку на оплату, принимает подтверждение и запоминает,
  у кого есть подписка. Цену в Stars нужно подобрать под ~300 ₽.
- **Напоминания.** Бот пишет ученику в нужное время («сегодня 25 вопросов до экзамена»).
  Нужен сервер с расписанием.
- **Проверка пользователя.** Любые платные права нужно проверять на сервере по подписи
  `initData`, а не по данным из приложения.
